# Recovered specimen media

Real microscopy replacements for exact unavailable upload URLs. No specimen is added by this manifest. Files are hosted locally. The legacy upload originals were not found in Git history; these are replacements, not claims to have recovered the same photograph.

Still images are unchanged from their credited sources. The sperm video is transcoded to H.264 MP4 without scene cuts or speed changes. The viewer fits the full image without cropping and maps labels to its native proportions. Display lenses are a simulation, not calibrated spatial measurements.

## Annotation review

Labels were placed afresh on the replacement images, not copied from the unavailable uploads. G6PD uses blister cells from confirmed G6PD deficiency, not the bundled schistocyte image. Sickle-cell labels distinguish a sickle cell from a target cell. The bacterial urine image labels only an unambiguous leukocyte; no tiny dot is asserted to be a specific organism. Moving sperm have no fixed markers.

Existing, already-working project assets have not been replaced or assigned an unverified license.
